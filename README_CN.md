# GULF 字幕文字 V2

独立运行，不修改 GULF Studio 主程序。

工作流：

**上传视频 → 本地 Whisper 英语识别 → 本地中文翻译 → 前 3 秒内容说明 → 960×540 审核代理 → 人工检查/修改 → 刷新审核预览 → 通过后生成最终 MP4 → 保存 SRT / ASS**

## Windows 一键启动

直接双击：

**run_gulf_subtitle.bat**

首次启动会在本项目目录创建：

**.gulf_venv**

所有 Python 依赖装在这个私有环境里，不污染系统 Python。

程序默认打开：

http://127.0.0.1:8765/ui/

## 第一次运行会发生什么

第一次处理视频时，本地 Whisper 和中文翻译模型可能需要下载。

模型下载完成后会保留在本机缓存，之后无需每次重新下载。

默认：

- Whisper：large-v3
- 设备：CPU 优先
- 识别语言：English
- 中文：本地模型翻译
- 审核代理：960×540
- 最终版：原画幅、不强制裁切、不变速
- 字幕：底部安全区，英文 + 中文双行

## 审核逻辑

程序不会因为低置信度就擅自修改原文。

低置信度字幕会标出：

- 红色：重点检查
- 黄色：建议检查
- 绿色：相对稳定

你可以直接在审片页面修改英文、中文和前三秒说明。

点击：

**保存修改并刷新审核预览**

程序会重新生成审核代理。

只有点击：

**审核通过，生成最终版**

才会进入最终高清编码。

点击：

**不好，删除这个视频**

会删除该任务目录中的源视频和生成文件。

## 文件位置

每次任务都保存在：

storage/jobs/<job_id>/

包含源视频、音频中间文件、审核 MP4、最终 MP4、SRT、ASS 和任务记录。

## 与 GULF Studio 的关系

这是一个独立的字幕 + 文字工具。

它不修改：

E:\GULF Studio\GULF Studio

也不需要 GULF Studio 的账号、密码或发布权限。

最终视频由你自行保存，再决定发布到哪个平台。

## 重要

“高精度”代表使用本地 Whisper large-v3 并保留人工审核环节，不代表任何模型都能做到百分之百无误。

程序明确禁止使用固定测试字幕或假发布结果。
